# Visione

LC Stencil Studio è un software professionale dedicato esclusivamente
alla progettazione e produzione di stencil.

L'obiettivo è semplificare l'intero flusso di lavoro:

- progettazione
- vettorizzazione
- creazione bridge
- gestione multilivello
- registro
- esportazione
